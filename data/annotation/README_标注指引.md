# 人工抽检指引 — LLM 供应链预警信号语义验证 (v2.1 · 第二轮盲标)

> 版本 v2.1 · 标注对象:`data/annotation/forward_spotcheck_v2_round2.csv`(52 条,与第一轮完全同一样本)
> 目的:对 v2 拆钟本体抽取的 forward 信号做**独立盲标抽检**,回答一个窄问题——
> "这些被 protocol 判定为 forward 的信号,在语义上是不是真的是'尚未发生的供应链中断预警'"。
> **这是第二轮独立标注:开始前和过程中,请勿查看、讨论或参考任何已有标注结果。**
> 注意:这是**抽检**(spot check);论文主体仍是"无完整人标"设计,本轮用于报告标注员间一致性与分歧仲裁。

---

## 一、你要做的只有一件事

对 CSV 里每一行,填最后两列:

**`human_label`**(每行必填):

| 值 | 含义 | 判定 |
|----|------|------|
| `1` | **真预警** | 报道发出时,它所警告的供应链中断(trigger)确实还没发生 |
| `0` | **非预警** | 不是预警:要么报道的是已发生的事实,要么与供应链中断无关 |
| `?` | **存疑** | 拿不准,或需要更多上下文才能判断 |

**`zero_reason`**(仅当 `human_label=0` 时必填,其余留空):

| 值 | 含义 |
|----|------|
| `unrelated` | 文章与本事件的供应链中断领域不沾边(关键词碰巧重合) |
| `already_occurred` | 文章描述的中断在报道发出时已经发生 |

**只填这两列,不要改其他列。**

---

## 二、核心判定标准(务必先读懂)

我们关心的是 **temporal direction**:这条信号是不是"向前看"的,即——

> **报道发出时,它所警告的供应链中断(trigger)还没有发生。**

五条规则:

1. **中断已发生 = 0。** 原文描述的是"已经发生的**中断**"(船已搁浅、工厂已停产、禁令已发布),即使 LLM 标成 forward,填 `0` 并写 `already_occurred`。
2. **未来风险 + 供应链后果 = 1。** 原文在说"某个情况可能导致/威胁/预期引发供应链中断",且中断尚未发生,填 `1`。
3. **无关 = 0。** 原文跟供应链中断不沾边(纯政治、体育、股市涨跌等),填 `0` 并写 `unrelated`。
4. **前兆事件已发生 ≠ 中断已发生(上一轮分歧最集中的一类)。** 判定对象是"**被警告的供应链中断**是否已发生",不是前兆本身。谈判已开始、威胁已发出、计划已公布、官方已警告,都只是"前兆已发生";只要它们指向的中断(航运中断、停产、禁运、短缺)还没发生,仍填 `1`。
5. **供应链后果可以是间接链条。** "地缘/政策/疫情前兆 → 可能影响航运/供应/价格",只要文中有这条链条,就算有供应链后果;纯政治博弈、全文不提任何供应/物流/商品影响的,按规则 3 处理。

**注意**:你判断的是"这条信号描述的内容",不是"LLM 抽得好不好"。**忽略 `confidence` 列**,它不参与判断。

---

## 三、怎么判(操作流程)

1. **先读 `description`**(中文,一句话概括)。
2. **再读 `trigger_phrases`**(LLM 认为支撑该信号的原文短语)。
3. **再读 `article_title` + `article_text`**(原文标题和正文前 2000 字),这是最终依据。
4. 如需,点开 `article_url` 看完整原文(失效不强求)。
5. 填 `human_label`。

**优先级:原文 > trigger_phrases > description。**

---

## 四、标注约定

- **只看"是否预警 + 是否供应链中断",不看"预警得对不对、准不准"。**
- **trigger_phrases 与原文对不上、但 description 语义仍是预警的**,以原文语义为准。
- **无法确定 trigger 是否已发生时**,填 `?`。
- **多义/跨事件**的,按"这条信号最可能指向的那个事件"判断。

## 五、示例

| 原文标题/关键句(节选) | human_label | zero_reason | 依据 |
|-------------------|-------------|-------------|------|
| "胡塞武装威胁袭击红海船只,航运可能绕行" | `1` | | 威胁(尚未袭击),规则 2 |
| "Top Biden aide says Ukraine invasion could come any day" | `1` | | 入侵尚未发生,纯预警,规则 2 |
| "沙特邀胡塞代表团赴利雅得停火谈判"(红海事件) | `1` | | 谈判已发生,但红海航运中断未发生,规则 4 |
| "DNR warns bird flu migrating across Iowa"(禽流感事件) | `1` | | 疫情向供应传导的风险未落地,规则 5 |
| "货轮今日在苏伊士运河搁浅" | `0` | `already_occurred` | 搁浅已发生,规则 1 |
| "Oklahomans voice earthquake concerns"(俄克拉荷马地震风险) | `1` | | 地震风险威胁当地油气供应链,规则 5 |
| "某公司发布财报,股价上涨" | `0` | `unrelated` | 无关供应链,规则 3 |
| "水位持续下降,或影响莱茵河航运" | `1` | | 未来风险,规则 2 |
